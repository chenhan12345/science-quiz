# 🔬 國中自然科理化 互動語音解題動畫・數位學習題庫系統

本專案為國中自然科理化教學專屬之互動題庫平台。
所有教材皆採用 **PageCrypt（AES-256-GCM 高強度加密演算法）** 保護，兼具版權安全、快速載入與清楚的差異化網址結構。
