## 🚀 二、從零開始：GitHub 註冊與部署教學（純網頁拖曳，免裝軟體）

### 步驟 1：免費註冊 GitHub 帳號（約 1 分鐘）
1. 請開啟瀏覽器前往：[https://github.com/signup](https://github.com/signup)
2. 輸入您的 **電子郵件信箱（Email）**。
3. 設定您的登入密碼，並取一個 **使用者名稱（Username，例如：`chenhan-study`）**。
4. 到信箱收取驗證碼完成信箱驗證，即可成功登入 GitHub！

---

### 步驟 2：在 GitHub 上建立專屬存放庫（Repository）
1. 登入後，點擊右上角的 **「+」號**，選擇 **「New repository」**（新增存放庫）。
2. 在 **Repository name** 欄位填寫專案名稱，例如：`science-quiz`。
3. 選擇 **Public**（公開，GitHub Pages 免費版需要設為 Public）。
4. 勾選 **「Add a README file」**（這樣存放庫建立後就會有主分支，方便直接上傳）。
5. 點擊最下方的綠色按鈕 **「Create repository」**。

---

### 步驟 3：在網頁上直接上傳加密好的網頁檔案
1. 進入剛建立的儲存庫頁面，點擊右上方的 **「Add file」** ➔ 選擇 **「Upload files」**。
2. 開啟您的電腦資料夾：`G:\AI測試\PageCrypt_網頁加密與GitHub託管專案`。
3. 將以下檔案直接拖曳（Drag & Drop）到瀏覽器視窗中：
   * `index.html`（**最重要的首頁檔案**）
   * `unit4-3_光的折射與透鏡.html`
   * `unit5-2_熱量與比熱.html`
   * `unit5-3_5-4_熱對物質與傳播.html`
   * `unit6-1_6-2_元素與純物質.html`
   * `portal.html`
4. 拖曳完畢後，拉到頁面最下方，點擊綠色的 **「Commit changes」** 按鈕儲存。

---

### 步驟 4：開啟 GitHub Pages 免費網頁功能
1. 在同一儲存庫頁面上方點擊 **「Settings」**（齒輪圖示）。
2. 在左側選單找到並點選 **「Pages」**。
3. 在 **Build and deployment** 下方的 **Branch**：
   * 第一個下拉選單將 `None` 改選為 **`main`**。
   * 資料夾維持 **`/ (root)`**。
4. 點擊右側的 **「Save」**（儲存）。

---

### 步驟 5：取得您的專屬線上學習網址！ 🎉
1. 儲存後約等待 1 ~ 2 分鐘，重新整理該 Pages 頁面。
2. 頁面頂端會出現綠色提示與您專屬的線上網址：
   > **`https://<您的使用者帳號>.github.io/<您的專案名稱>/`**  
   > *(例如：`https://chenhan-study.github.io/science-quiz/`)*
3. 學生或任何人開啟此網址時：
   * 畫面會彈出專業的密碼保護對話框。
   * 輸入通關密碼：**`chenhan`**。
   * 點擊「解密開啟」即可立即載入解題動畫！
   * 任何人在沒有密碼的情況下，即使下載或右鍵檢視原始碼，也絕對無法看到任何題材內容與答案！
